# Zhi for Zed

Import `xuan-light.json` or `xuan-dark.json`, then select **Zhi Light** or **Zhi Dark** in Zed's theme selector.

Edit these native JSON files directly. From the repository root, `pnpm themes:build` includes them in the Zed download archive. They do not require compilation.

The legacy filenames are retained for compatibility. Existing users must select the renamed theme; personal settings are not migrated automatically. Editor and syntax colors are preserved during the repository migration.
