# 纸 · Zhi 设计规范

状态：0.3.0 Preview，16 个可安装组件；仍是早期版本。

纸以笔墨纸砚为基础：以字重和浓淡表达墨色，以轻微纹理和直角表面表达纸，以留白和对齐组织内容。朱色用于少量印记、焦点与必要提示，竹色提供另一种安静的强调色。控件保持清楚、熟悉的交互方式，不需要在每处都放上毛笔或砚台图案。

## 主题

- 白纸：参考雪与纸的清白，适合日常工具。
- 宣纸：温润的纸白与墨色，适合阅读和书写。
- 墨纸：深色表面与暖白文字，适合夜间使用。
- 青竹：以竹的绿色为强调，适合阅读偏好、设置和需要绿色识别的界面，主题 ID 为 `qingzhu`。

四个主题共用尺寸、组件结构和交互；颜色通过语义变量切换。`design/tokens.json` 为唯一 token 源，`registry/themes/zhi.css` 由脚本生成。

`pnpm tokens:build` 同时生成 `registry.json` 中 theme 条目的 CSS 与 `cssVars`。这些字段随 token 更新，其余组件条目手工维护。

## 排版与空间

- 正文及控件使用 Noto Sans SC；展示标题少量使用 Noto Serif SC。网页通过 Fontsource 本地依赖加载字体。
- 正文 14/24，标签 14/20，辅助文字 12/20，章节标题 20/30，展示标题 32/48。
- 间距基于 4 px，常用 8、12、16、24、32、48、64 px。
- 默认控件高 36 px，小号高 28 px；控件和组合容器的圆角 token 均为 0 px，使用纸张式直角。
- Checkbox 和 Switch 延续方正轮廓；Radio 保留圆形，让单选与复选仍容易区分。
- 左边界、文字基线、标签和输入区域保持一致；数值列右对齐。

## 细节与自然元素

按钮的实心与描边层级借鉴印章的朱白对比，方正边界保持稳定；缺口、磨损与印泥纹理只用于品牌印记，不侵入控件标签或焦点线。卡片和弹窗以纸面、细边与间距建立层次，不依赖圆角和厚重阴影。

笺纸的界栏可用于分组与侧栏，落款式小字可用于作者、版本或日期。它们先承担信息作用，再表达中式气质；竖排限于短小的装饰性题签，正文与控件标签保持易读的常规排版。

自然元素是可选素材，按场景选择，而不是给每个组件加花纹：

| 元素 | 适合的位置 | 使用方式 |
| --- | --- | --- |
| 竹 | 青竹主题、设置区、竖向构图边缘 | 少量竹叶和竹节，绿色通过语义 token 统一设置 |
| 雪 | 白纸主题、大面积留白、纸面细节 | 稀疏静态点和轻微纹理，避开文字与控件内容 |
| 云 | 空状态、等待预览的背景、章节留白 | 低对比的横向线条，文字仍明确说明当前状态 |
| 雨 | 进度区旁、文档页边、安静的背景 | 细短斜线，作为可选装饰，不改变进度语义 |

这些图形使用原创 SVG，见 [设计资源](resources.md)。装饰不可拦截点击，不参与可访问名称，也不替代错误、加载或选中状态。文字背后不持续播放雨雪粒子；纸纹保持低对比，三种浅色与深色主题都要检查可读性。

## 组件范围

Figma：主题对照、色彩和文字样式、间距规范、Button、Input、Checkbox、Switch 的可编辑组件及状态示例。基础组件的主组件与评审实例分区保存。

代码：16 个组件、四个主题、可交互预览与 Registry 构建。当前目录及组合 API 见 [组件目录](components.md)。

0.2 新增 Textarea、Label、RadioGroup、Select、Card、Badge、Separator、Alert、Progress、Tabs、Accordion、Dialog。当前表单使用 36 px 控件高；卡片和弹窗使用 24 px 内边距，统一采用直角表面。Tabs 通过字色与底边区分选中状态，Accordion 通过间距和分隔线组织内容。Select 和 Dialog 的浮层继承页面主题；键盘、禁用、焦点管理交给 Base UI。

Progress 支持明确进度和未知进度；未知进度使用静态短条及文字说明，避免持续动画。Alert 默认是静态提示，动态紧急信息可显式传入 `role="alert"`。朱色用于错误与焦点，状态同时通过文字或语义属性表达。

首轮评审检查：中英文和长标签可读；默认、焦点、禁用与错误状态有区别；主题切换后主要操作清楚；留白与对齐在真实组合中成立。

## Figma

[纸 · Zhi — Component Library](https://www.figma.com/design/XWvrkynXWsb4ezYtAGu6SV?node-id=4-2)

Figma 当前保留 0.1 历史设计：100 个变量、6 个文字样式、12 组主组件、72 个状态变体，覆盖最初四个组件和原有三个主题，仍含旧圆角。新增组件、直角规则、青竹主题与自然素材以当前源码、tokens 和资源目录为准，尚未同步成 Figma 主组件。文件及组件 ID 保存在 `design/figma.json`，后续优先更新已有节点。

Figma 使用本项目自有组件与变量。可访问的社区 UI kit 不属于「纸」的设计资产，不引入其默认视觉规范。

设计资源与代码同用 MIT 许可，目录及使用方式见 [design/README.md](../design/README.md)。仓库保留原有三主题组件 SVG、评审图、变量和文字样式快照，并提供新的原创自然素材。历史快照不作为当前 token 来源；SVG 不保留 Figma 的组件关系，原生 `.fig` 文件尚未导出。字体继续遵循独立的 SIL OFL 1.1 许可。
