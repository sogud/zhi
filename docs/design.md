# 纸 · Z 设计规范

状态：第一轮探索，供评审与修改；对应 0.1.0 Preview，不是完整组件库。

纸以排版、留白、对齐和墨色层次表达中式美学。控件保持清楚、熟悉的交互方式。朱色只用于少量标记、焦点与必要提示。

## 主题

- 白纸：清白、明晰，适合日常工具。
- 宣纸：温润的纸白与墨色，适合阅读和书写。
- 墨纸：深色表面与暖白文字，适合夜间使用。

三个主题共用尺寸、组件结构和交互；颜色通过语义变量切换。`design/tokens.json` 为唯一 token 源，`registry/themes/zhi.css` 由脚本生成。Figma Starter 每个集合只有一个 mode，因此三种主题使用三个语义颜色集合，语义值引用同一基础色集合。

`pnpm tokens:build` 同时生成 `registry.json` 中 theme 条目的 CSS 与 `cssVars`。这些字段随 token 更新，其余组件条目手工维护。

## 排版与空间

- 正文及控件使用 Noto Sans SC；展示标题少量使用 Noto Serif SC。网页通过 Fontsource 本地依赖加载字体。
- 正文 14/24，标签 14/20，辅助文字 12/20，章节标题 20/30，展示标题 32/48。
- 间距基于 4 px，常用 8、12、16、24、32、48、64 px。
- 默认控件高 36 px，小号高 28 px；控件圆角 6 px，组合容器圆角 12 px。
- 左边界、文字基线、标签和输入区域保持一致；数值列右对齐。

## 第一轮范围

Figma：主题对照、色彩和文字样式、间距规范、Button、Input、Checkbox、Switch 的可编辑组件及状态示例。基础组件的主组件与评审实例分区保存。

代码：同名组件的起步实现、三个主题、组件预览、Registry 构建。扩展组件在确定本轮视觉方向后逐步加入。

首轮评审检查：中英文和长标签可读；默认、焦点、禁用与错误状态有区别；主题切换后主要操作清楚；留白与对齐在真实组合中成立。
